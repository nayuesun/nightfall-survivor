# 밤의 파수꾼 · Nightfall

https://nayuesun.github.io/nightfall-survivor/

10분 생존 액션 게임입니다. PC는 WASD/방향키, 모바일은 전장 화면을 누른 채 드래그해서 이동하세요. 손을 떼면 멈추고 공격은 자동입니다.

- 시작 무기 8종 중 선택, 무기와 방어 아이템은 각각 최대 5단계.
- 몬스터를 처치하고 경험치를 모아 장비를 강화합니다.
- 단검·마법탄·도끼는 사거리 안의 기존 표적을 계속 공격합니다.
- 상단에서 몬스터 처치 수 확인과 일시정지·재시작이 가능합니다.
- 난이도 하/중/상은 최초 기준 몬스터 체력과 등장 수 2/3.5/5배입니다.
